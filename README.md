# 삼국지14 CE 편성기

보유 장수와 현재 시나리오를 입력해 여러 전선의 주력·진형·지원·예비를 편성하는 한국어 정적 웹 앱이다. 저장소를 내려받아 `docs/index.html`을 브라우저로 열면 실행할 수 있다.

## 프로젝트의 편성 알고리즘 v1.0

기본 편성 엔진의 기준은 [편성 알고리즘 v1.0 명세](FIELD_PLANNER_V1.md)다. 유비·조조·손권계 실험으로 정한 공방 안정화, 집단 분할, 주력·지원 선발, 시나리오별 관계, 3인 의형제·결혼 추천 및 가정 적용까지를 한 버전으로 묶는다. 이 범위를 완성한 [기준 구현](https://github.com/seraveist/SAN14-Affinity/commit/2d122cf4c308640a8a8d2c4f6709261b5e41ce64)과 24개 자동 편성 결과를 보관한다.

| 사용 단계 | 확인할 수 있는 내용 |
| --- | --- |
| 초안 만들기 | 집단별 주력 최대 5명과 진형, 출진 지원 최대 1명, 집단 정원 10명 내의 예비와 미편성 |
| 편성 비교 | 같은 명단과 중개 가정에서 집단 수별 출진 인원, 최저 공군·방어, 양축의 격차, 고립 주력 |
| 중개 검토 | 결의·혼인의 평시 및 합류 효과, 교대·지원 이동 손익, 중개 전후의 공방 하한 |
| 채택과 기록 | 선택한 안을 현재 편성에 적용하고 직전 상태로 복원하거나 편성표를 텍스트로 복사 |

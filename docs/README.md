# 삼국지14 친애 편성기

보유 장수 명단으로 편성을 만들고, 집단 이동과 집단 수 변경을 비교하고, 함께 출진할 장수와 진형을 확인하는 정적 웹 앱입니다.

`docs/index.html`을 브라우저에서 열면 실행됩니다. 배포 시 GitHub Pages의 소스로 `docs/`를 사용합니다.

## 편성 흐름

1. 이름을 넣고 **명단 확인**을 누르거나 조조·유비·손권·원소 프리셋을 선택합니다. 동명이인은 번호와 능력치를 보고 고릅니다. 쉼표, 공백, 줄바꿈, `장포(2)` 및 `#ID`를 지원합니다.
2. 자동분할 또는 1~10집단, 고정 코어를 정하고 **초안 만들기**를 누릅니다. 자동 배정은 집단당 15명 기준으로 계산하며 초과하는 수동 이동에는 경고를 표시합니다.
3. **옮길 집단 찾기** 또는 **집단 수 바꿔보기**로 현재와 변경안을 비교합니다. 반영한 변경은 한 단계 실행 취소할 수 있습니다.
4. **보완안 찾기**에서 의형제와 결혼을 가정해 비교합니다. 결혼에는 배우자 상태의 미확인을 표시합니다.
5. **출진 후보 고르기**에서 장수당 진형 하나를 선택합니다. 채운 역할과 직접 관계, 미편성 보좌 장수의 가세 후보를 확인하고 출진 목록을 복사합니다.

집단 내 직접 관계 수와 편성 점수는 앱의 비교 지표입니다. CE의 군단·거리·상태 조건은 출진 후보의 확인 항목입니다. [공식 CE 연계 조건](https://www.gamecity.ne.jp/manual/sangokushi14-pk/ce/kor/5110.html)

**장수 찾기**는 장수명, 개성, 진형을 검색하며 보유 장수 필터와 상세 정보를 제공합니다. CE 개성 설명에는 원본 대조 일자와 콜라보 기본 구성 여부가 표시됩니다.

장수 상세의 **개인 친애**는 CE 1.0.2 기준 시나리오에서 확인한 일방·쌍방을 보여줍니다. **전투 연결**과 편성의 **연결 근거 보기**는 개인 친애, 확인된 혈연, 기존 연계 등급을 표시합니다. 기준 시나리오와 관계가 다른 일부 장수는 개인 친애 상세에 안내합니다.

편성 결과와 출진 후보에서 직접 연결된 장수와 2명 이상에게 연결된 장수를 각각 셉니다. 일방·쌍방 관계의 두 장수는 서로를 한 번씩 직접 연결로 셉니다. ☆·◎는 기존 연계 자료를 근거로 별도 집계합니다. 대상이나 등급이 상충하는 기존 기록은 연계 등급 산정에서 제외합니다.

## 소스와 데이터

| 파일 | 역할 |
| --- | --- |
| `model.js`, `roster.js` | 장수·관계·점수 조회, 명단 해석과 편성 조건 |
| `planner.js`, `recommendations.js` | 코어 중심 편성, 자동분할, 의형제·결혼 보완안 |
| `campaign.js` | 이동·전후 비교, 관계 자료 상태, 출진 진형 평가 |
| `app.js`, `formation-view.js`, `dex.js`, `ui.js` | 화면 상태, 편성·도감 렌더링, 공통 UI |
| `data.js` | 브라우저에 배포하는 생성 데이터 |
| `profile_data.json` | 기존 배포 데이터의 일본어 출처 상세, 진형, 개성 설명과 능력치 보완 필드 |
| `ce_traits.json` | 2026-10-31에 한국어 CE 원본과 대조한 개성 설명과 구성 여부 |
| `ce_affinity.json` | 한국어 CE 1.0.2 기준 시나리오 `scedaexce01.s14`의 장수별 친애 대상·혈연 ID와, 일부 시나리오의 추가 친애 |

데이터를 갱신할 때는 Python에 `openpyxl`을 설치한 후 저장소 루트에서 실행합니다. 입력은 루트의 `affinity_index.json`과 엑셀이며, 필요하면 `SAN14_AFFINITY_JSON`과 `SAN14_WORKBOOK`으로 지정합니다. 관계 자료에서 대상이 누락되거나 모호한 행과 등급이 상충하는 행을 보존해 UI에서 확인할 수 있습니다.

```powershell
python docs/build_data.py
python docs/build_data.py --check
node docs/verify.mjs
node docs/regression_runner.mjs --compare
```

회귀 비교는 기준 커밋 `c5ba4fc`의 엔진과 데이터를 읽어 고정 4집단 프리셋을 비교합니다. CE 친애 및 혈연 연결을 반영한 현재 점수와 과거 점수가 다르면 해당 차이를 출력하고 종료 코드를 1로 설정합니다.
